### Key Concept: Subqueries

A subquery is a query placed inside another SQL query.

Conceptually:

**Outer Query → Inner Query → Result → Final Output**

Practicing subqueries helped improve my ability to approach SQL problems that cannot be solved efficiently using only a single-level query.

## 💻 Problem-Solving Approach

My general approach to the SQLZoo exercises was:

**Understand the Problem → Identify the Inner Query → Build the Subquery → Connect It to the Outer Query → Validate the Result**

This approach helped break complex SQL problems into manageable steps.
